[노드가디언 업데이트] v1.3.1 — 재부팅 시 관리자 권한 자동 실행

이번 업데이트부터 PC 재부팅 시 노드가디언이 자동으로 관리자 권한으로 실행됩니다.
관리자 권한으로 실행되어야 메모리 최적화 기능이 정상 작동하므로 꼭 업데이트해주세요.

변경 사항
• 재부팅 시 UAC 승인 없이 자동으로 관리자 권한 실행
  - 기존: Windows 시작 프로그램(레지스트리) 방식 → 일반 권한 실행
  - 변경: Windows 작업 스케줄러 방식 → 관리자 권한 자동 실행
• 트레이 메뉴에 ⚙️ 설정 다시 열기 추가


업그레이드 방법 (기존 사용자)

1. NodeGuardian.exe가 있는 폴더에서 .env 파일과 logs 폴더를 삭제합니다

2. 기존 NodeGuardian.exe를 삭제하고 새 버전을 다운로드합니다
   다운로드: https://github.com/kmm851010-maker/node-guardian/releases/tag/v1.3.1

3. 새 NodeGuardian.exe를 우클릭 → 관리자 권한으로 실행합니다

4. 설정 마법사가 자동으로 열리면 Pi 닉네임을 다시 연동하고
   시작 프로그램 등록에 체크합니다

이후 재부팅부터 UAC 없이 관리자 권한으로 자동 실행됩니다.
