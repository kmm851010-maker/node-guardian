[노드가디언 업데이트] v1.3.0 — 메모리 자동 최적화 기능 추가

Pi 노드 PC를 오래 켜두면 메모리 점유율이 서서히 올라가면서 PC가 느려지거나 재부팅이 필요해지는 문제가 있었습니다.
이번 업데이트부터 노드가디언이 실행 중인 동안 자동으로 메모리를 정리해 줍니다.

새로운 기능
• 30분마다 자동으로 Windows 메모리 최적화 실행
  - 모든 프로세스의 메모리 Working Set 해제
  - Modified Page List 정리
• 트레이 아이콘 우클릭 메뉴에서
  - 지금 바로 최적화 실행 가능
  - 자동 최적화 ON/OFF 토글 가능

업그레이드 방법
기존 NodeGuardian.exe를 새 파일로 교체하면 됩니다.
설정 파일(.env)은 그대로 유지됩니다.
